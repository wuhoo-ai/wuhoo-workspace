# 矿工守夜 (Miner's Watch) — Game Design Document

> 版本: 0.1 | 日期: 2026-07-13 | 状态: 热身项目 GDD

---

## 1. 游戏概述

### 1.1 一句话描述

白天挖矿攒资源，夜晚建防御活下来，层层深入直到击败 Boss。

### 1.2 参考游戏

- Dave the Diver — 日夜分离结构、2D+3D 混合视觉
- Kingdom (系列) — 简化的横版防御建造
- SteamWorld Dig — 挖矿下探+资源升级

### 1.3 目标平台

Windows / Android / iOS (Unity 6 + URP)

### 1.4 技术路线

- 2D 像素角色 (Aseprite + pixel-art skill)
- 3D 低多边形洞穴背景 (Blender)
- Unity URP 混合渲染 (Sprite Renderer + Mesh Renderer)
- GameCI + GitHub Actions 每日构建

## 2. 核心 Loop

```
┌──────────────────────────────────────────────────┐
│                                                    │
│  白天 (120 秒)                                      │
│  ┌─────────────────────────────────────┐          │
│  │ 洞穴中自由移动 (横版 2D)               │          │
│  │ 镐挖掘矿物 (5 种, 价值递增)            │          │
│  │ 体力管理 (100 → 0 → 不能继续挖)        │          │
│  │ 电梯返回地面 (任何时间)                │          │
│  └─────────────────────────────────────┘          │
│           │                                        │
│           ▼                                        │
│  地面 (操作阶段)                                    │
│  ┌─────────────────────────────────────┐          │
│  │ 商店: 卖矿物 → 获得金币               │          │
│  │ 升级: 镐/护甲/背包 (金币购买)         │          │
│  │ 建造: 木墙/陷阱/炮塔 (金币+材料)       │          │
│  │ 选择深度: 浅/中/深 (新层需通关前一     │          │
│  │           层 Boss 后解锁)             │          │
│  └─────────────────────────────────────┘          │
│           │                                        │
│           ▼                                        │
│  夜晚 (90 秒)                                      │
│  ┌─────────────────────────────────────┐          │
│  │ 3 波怪物从左侧涌来                    │          │
│  │ 防御工事自动/半自动攻击               │          │
│  │ 玩家可用镐辅助战斗                    │          │
│  │ 守住基地核心 (HP > 0) → 胜利          │          │
│  │ 怪物掉落材料 (用于建造/特殊升级)       │          │
│  └─────────────────────────────────────┘          │
│           │                                        │
│           ▼                                        │
│  结算 → 下一循环                                    │
│                                                    │
└──────────────────────────────────────────────────┘
```

## 3. 系统设计

### 3.1 采矿系统

| 参数 | 值 |
|------|-----|
| 玩家体力 | 100, 每挖一次消耗随矿物硬度变化 |
| 矿物列表 | 石(1体力,卖$5) / 铁(2体力,卖$15) / 金(5体力,卖$40) / 水晶(10体力,卖$100) / 黑曜石(20体力,卖$300) |
| 矿物分布 | 浅层: 石+铁 / 中层: 铁+金+水晶 / 深层: 金+水晶+黑曜石 |
| 背包容量 | 初始 10 格, 每格堆叠 5。升级后 20/30 格 |
| 镐等级 | Lv1(基础) / Lv2(体力消耗-30%) / Lv3(挖黑曜石只需 10 体力) |

### 3.2 升级系统

| 升级 | 等级 | 效果 | 费用 |
|------|------|------|------|
| 镐 | Lv1→2→3 | 体力消耗递减 | $200 / $800 |
| 护甲 | Lv1→2→3 | 夜晚 HP +20%/+50%/+100% | $150 / $600 |
| 背包 | Lv1→2→3 | 容量 10→20→30 格 | $100 / $400 |

### 3.3 防御建造系统

| 工事 | 费用 | HP | 效果 |
|------|------|-----|------|
| 木墙 | $50 | 50 | 阻挡怪物, 可堆叠 3 层 |
| 尖刺陷阱 | $80 + 5铁 | 30 | 怪物经过时造成 20 伤害, 3 次后损坏 |
| 炮塔 | $200 + 3金 | 40 | 自动射击, 每 2 秒 15 伤害, 范围 5 格 |

玩家在白天可自由摆放 (地面层, 横版 2D 布局, 约 15 格宽)。

### 3.4 敌人系统

| 敌人 | 出现层 | HP | 伤害 | 速度 | 掉落 |
|------|--------|-----|------|------|------|
| 石虫 | 浅层 | 30 | 10 | 慢 | 铁 1-2 |
| 暗影 | 中层 | 80 | 20 | 中 | 金 1 + 暗影碎片 |
| 熔岩兽 | 深层 | 200 | 35 | 快 | 水晶 1 + 熔岩核心 |
| Boss: 地心守卫 | 深层第 5 夜 | 500 | 50 | Boss 模式 | 黑曜石 5 + Boss 奖杯 |

夜间波次: 第 1-2 波小怪随机 / 第 3 波含中型怪。出现层 = 当前解锁最深层的敌人池。

### 3.5 深度解锁

```
浅层 (Level 1):
  矿物: 石 + 铁 | 敌人: 石虫
  解锁条件: 初始可用
  夜晚难度: 1-3 波石虫 (3/5/8 只)

中层 (Level 2):
  矿物: 铁 + 金 + 水晶 | 敌人: 暗影
  解锁条件: 在浅层累计挖矿 $500
  夜晚难度: 1-2 波石虫 + 1-2 波暗影

深层 (Level 3):
  矿物: 金 + 水晶 + 黑曜石 | 敌人: 熔岩兽
  解锁条件: 在中层累计挖矿 $2000
  夜晚难度: 暗影 + 熔岩兽, 第 5 夜 Boss
```

## 5. 技术规格

| 项 | 规格 |
|-----|------|
| 引擎 | Unity 6 (最新 LTS) |
| 渲染管线 | URP |
| 渲染模式 | 2D 像素 Sprite + 3D Mesh 混合 |
| Cinemachine | 横版跟随相机, 白天有边界, 夜晚固定 |
| 输入 | Input System (键鼠+触屏虚拟摇杆) |
| 存档 | JSON, 版本号, 自动备份 3 份 |
| 目标帧率 | 60fps (Win), 30fps+ (移动端) |
| 分辨率 | 1920×1080 基准, 自适应 |
| 包体 | < 100MB (移动端) |

## 6. 数值平衡 (初始值, 待验证)

```
武器平衡:
  镐 Lv1: 石 1体力/$5 净赚 = $5/体力 (基准)
  镐 Lv2: 金 3.5体力/$40 = $11.4/体力 (vs Lv1 $8/体力 in 中层)
  镐 Lv3: 黑曜石 10体力/$300 = $30/体力 (深层专享)

经济平衡:
  升级总费用: 镐 $1000 + 护甲 $750 + 背包 $500 = $2250
  浅层单趟收入: ~10石+5铁 = $125 (约 18 趟满升级)
  中层单趟收入: ~10铁+5金+3水晶 = $650 (约 4 趟满升级)
  深层单趟收入: ~5金+5水晶+2黑曜石 = $1300

防御平衡:
  浅层夜晚: 3波石虫 (3/5/8只, 总 HP 240) vs 木墙 50HP×3 = 150HP
          → 需玩家辅助, 木墙不够用
  深层夜晚: 暗影+熔岩兽 (总 HP ~800) vs 炮塔×2 伤害 15/2s
          → 需陷阱+炮塔+木墙组合
```

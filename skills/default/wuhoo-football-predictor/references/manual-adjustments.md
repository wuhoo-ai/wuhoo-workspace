# Layer 6 手动调整 — 操作指南

## 何时使用

模型的前 5.5 层（ELO / 伤病 / 教练 / 场馆 / 天气 / 赛程 / 热身赛 / 锦标赛 / RSS / LLM信号）
覆盖了可量化的结构化因子。但以下类型的事件**必须**通过 Layer 6 处理：

- **队内矛盾**: 公开冲突、信任裂痕、更衣室分裂
- **场外干扰**: 丑闻、法律问题、极端球迷事件
- **突发状态变化**: 主力球员赛前生病（未被伤病追踪覆盖）
- **战术体系崩塌**: 教练失去更衣室控制、核心球员公开质疑战术

| 6/19 | C罗姐姐Katia Aveiro暗示队友"神奇忘记如何踢球" | Yahoo TW |

| 6/20 | 菲戈: "C罗跑动范围缩水，只会蹲禁区等传球" | 腾讯新闻 |

| 6/21 | BBC标题《不敢换下的老将，正在拖垮葡萄牙进攻》 | BBC |

### 评估

- **严重程度**: 高 — 涉及队内核心球员+队长公开冲突，社交媒体发酵
- **对比赛影响**: 队内信任下降 → 传球配合减少、防守协防意愿降低、士气受挫
- **调整幅度**: -30 ELO（中等保守。低于教练下课级别-50，高于单纯粉丝骚扰-15）
- **有效期**: 6/28（小组赛最后一轮后重新评估）

### 效果

| 指标 | 无调整 | 含-30 | 变化 |
|------|--------|-------|------|
| Portugal 有效ELO | 1858 | 1828 | -30 |
| vs UZB 胜率 | 69.8% | 68.3% | -1.5pp |
| 判定 | 中置信度 | 中置信度 | 不变 |

-30 ELO 未翻转结果（Portugal对UZB实力差距太大），但缩小了胜率差距。
如果面对实力相近的对手（如 vs Colombia），-30 可能改变判定方向。

## 创建新调整的流程

1. **采集证据**: `web_search` 中英文双向搜索，至少 2 个独立来源
2. **确认事件**: 非单一来源谣言，有视频/截图/名宿确认更佳
3. **评估幅度**: 参考调整幅度指南（见 SKILL.md Layer 6 章节）
4. **写入文件**: 编辑 `data/manual_adjustments.json`，填入完整 evidence
5. **重跑预测**: `python3.11 scripts/predict_by_date.py --tomorrow --news`
6. **生成报告**: `python3.11 scripts/generate_daily_report.py --date <date>`
7. **验证效果**: 检查预测 JSON 中 `layers.6_manual` 和 `effective_elo` 是否正确

## 常见错误

1. **调整过大**: -50 以上通常过高。记住 Layer 6 是补丁，不是主模型
2. **无证据支撑**: 单一来源的传闻不应触发调整
3. **忘记过期**: 比赛过后的事件仍留在文件中，影响后续预测
4. **未重跑预测**: 修改 `manual_adjustments.json` 后必须重新运行 `predict_by_date.py`，cron 的 15:00 自动运行不会自动反映刚修改的文件（除非在 cron 触发前完成）

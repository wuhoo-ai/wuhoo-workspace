## 五、关于本预测

- **模型**: Elo 评分（2100-scale）+ Poisson 进球分布 + FIFA 官方淘汰赛对阵表
- **模拟**: 10,000 次 Monte Carlo 全流程模拟
- **球场因素**: 16 个球场，建模海拔（Azteca 2200m）和高温（Miami, Dallas 等）对非适应球队的惩罚
- **平局处理**: KO 阶段概率化打破（非确定性强队胜），ELO 差 0 → 50:50
- **已知局限**: 无实时伤病/阵容/教练数据，ELO 为静态数据（2026-05-01），小组赛无 venue 建模

## 五、关于本预测

- **模型**: Elo 评分（2100-scale）+ Poisson 进球分布 + FIFA 官方淘汰赛对阵表
- **模拟**: 5,000 次 Monte Carlo 全流程模拟
- **集成功能 v2.3**: 伤病(INJURIES), 教练/磨合(META), 锦标赛形态 N(0,60), 同洲代理新闻情感，建模海拔（Azteca 2200m）和高温（Miami, Dallas 等）对非适应球队的惩罚
- **平局处理**: KO 阶段概率化打破（非确定性强队胜），ELO 差 0 → 50:50
- **冷门模型 v2.3**: 动态冷门上界 22% + 每场 N(0,25) 抖动 + 40% 比分扰动 + 锦标赛形态 N(0,60)
- **新闻情感 v2.3**: 未启用（--news 参数可选）
- **已知局限**: ELO 为 2026-05-21 静态数据；小组赛 venue 建模已启用；伤病/教练数据需手动维护

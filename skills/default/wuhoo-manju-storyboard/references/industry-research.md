## 一、AI 漫剧主流生产流程（多源一致）

来源：

- 漫剧制作教程：小说→脚本→角色→分镜→视频全流程 https://www.krene.com/blog/ai-video-comic-drama-tutorial
- AI漫剧全流程制作教程（知乎）https://zhuanlan.zhihu.com/p/2059938862093317105
- 2026年AI漫剧分镜图教程 https://www.tahou.com/article/212312705085840389

共识流程：
```
小说/剧本 → LLM生成分镜脚本 → 角色设计(一致性基准) → 逐镜头关键帧静帧
→ 图生视频(首帧参考) → 配音/音效 → 剪辑合成
```

关键经验（逐条可执行）：
1. **分镜密度**：1-2分钟短片 ≈ 8-15 个分镜，不要贪多；每镜头静帧对应 3-8 秒视频。
2. **分层生成比一次性输出可靠**：先高质量生图定格关键帧，再作首帧参考让画面动起来。
3. **角色一致性是最大挑战**：10个场景里主角「不换脸」直接决定质感。
   主流解法=基准照片法：基础提示词生成满意的主角样图 → 后续所有镜头当参考图
   （即梦参考图模式/可灵主体参考/wan3.0 reference_image 同构）。
4. **分镜脚本的价值=把故事变成画面清单**：每镜头谁出现、做什么、镜头远近、
   台词在哪句出现，都在分镜阶段定死；拆得越清楚，后面生成越省事。
5. 分镜提示词角色设定（Krene 模板）：「电影分镜设计师 + AI绘图提示词工程师」，
   每镜头独立一条生图提示词，角色出现必加一致性描述。
6. 镜头语言规范：景别（远/全/中/近/特）+ 运镜（推拉摇移跟）+ 时长 + 转场，
   与传统影视分镜表同构——AI 漫剧没有发明新格式，是把传统分镜表喂给生成模型。

共性结论（跨家一致，写进本技能纪律）：
1. 主体要具体：「一只猫」不如「一只橘色的短毛猫」。
2. 动作要简单：「跳舞转圈跳跃」不如「慢慢走过」——复杂连续动作是生成模型弱项。
3. 镜头要明确：景别+运镜写进 prompt 才有电影感；固定机位要显式声明。
4. 光影/氛围/风格是美学控制层，与主体/运动层分开写。
5. 负向清单只写排除项，不凑数。

## 三、Wan3.0 特有能力（漫剧相关）

- 原生多镜头叙事：≤30s，序号+时间戳+分镜内容，镜头间保持主体/场景/氛围一致；
  自动生成同步台词、BGM、音效（audio=true 默认）。
- 全模态参考：主体/运动/风格/音频/白模/多宫格分镜图/关键帧序列/文件网页。
- **多宫格分镜图参考**：一张排好格的分镜图 → 按剧情推演视频（漫剧分镜表可直接视觉化喂入）。
- **关键帧参考**：多张关键帧图按顺序对齐成视频（③阶段产物直接可用）。
- 视频延长：前/后/双向续写（镜头不够长时延长，比重生成便宜）。
- 音色克隆+口型同步：台词镜头的进阶层（首试产避开）。
- 官方 prompt 优化 Skill（wan3-pe）：五段式格式化整理，忠实性11条（见 wan3-pe-format.md）。

## 四、guimei 差异化定位

业界漫剧多为写实/二次元爽文改编；guimei 漫剧的差异化=
皮影柔情国风美学（决策110）+ 宿命感演出语言（13五要素/六模式）+
唐传奇对白浓度（08）+ 含蓄叙事（37六通道/三问法则）。
这套规范是 GDD 定稿资产，业界没有现成替代——分镜技能的核心价值就是把它们
翻译成 Wan3.0 能执行的提示词语言（映射表见 guimei-cinematic-mapping.md），
而不是套用业界通用爽文分镜模板。

## 完整提示词公式（全模态场景推荐；想控制什么就写什么，控不到的板块跳过）

```
提示词 = [总体描述]
       + [参考素材引用：图 N / 视频 N / 音频 N]
       + [分镜 N（起-止秒）：主体 + 场景 + 运动 + 美学控制]
       + [台词：xx 说："xxxx"]
       + [音效 / BGM]
       + [风格 / 情绪]
       + [负向清单]
```

官方综合示例（参考生视频+多镜头+台词+音色参考+风格控制，节选骨架）：

```
东方史诗仙侠，霸气雄浑。身披重甲的将军手持长枪，独骑一只金色麒麟，镇守两山之间的雄关关前，
远处敌军黑潮压境。15 秒，节奏由沉稳压抑转为爆发。将军形象参考图1，面部神态参考图2，
坐骑参考图3，音色参考音频1。
分镜1（00:00-00:03）：大远景建立镜头，24mm 广角，极低角度仰拍，摄影机静止。……
分镜2（00:03-00:06）：近景特写，85mm 长焦，浅景深。……将军低沉开口："此关，我守了十年。"
分镜3（00:06-00:10）：中近景略仰视，摄影机极缓推进。……沉声道："今日，一个都别想过去。"
分镜4（00:10-00:15）：摄影机沿将军 120 度弧线环绕并下沉至极低角度，转大远景。……
风格情绪：东方史诗，IMAX 感大场面，变形宽银幕，电影感，胶片颗粒，高动态范围；悲壮、孤峙。
负向清单：无现代元素、无字幕水印、无多余人物、避免面部畸变与穿帮、避免画面模糊与低分辨率。
```

## 参考素材引用

- 素材按上传顺序编号，图/视频/音频分别计数：第1张图=图1，第1段视频=视频1（图1与视频1可并存）。
- 编号必须与上传顺序一致，否则引用错素材。
- 只有一个素材可简写「参考图片/参考视频」；两个及以上必须写编号。
- 同一素材可多处引用，用途分开各引一次（形象/动作/音色/场景）。

| 想实现什么 | 参考写法 |
|---|---|
| 单纯锁形象 | 图1的儿童站在图2的现代公寓玄关内 |
| 多素材混合 | 图1手中拿着图2，走进视频1的场景 |
| 音色克隆 | 音色参考音频1；按音频1的音色说："xxxx" |
| 只借运动/运镜 | 参考视频的运镜方式，场景改为…… |
| 只借动作 | 视频1中的滑板男人替换为图1中的女人，滑板动作、轨迹和场景保持不变 |
| 只借特效 | 图1人物按照视频1的能量特效，生成同样的火焰燃烧特效和动作 |
| 只借风格 | 风格参考图2；仅参考图2的色调与光影，不参考人物 |
| 文档/网页 | 根据我的提案文档，生成某品牌广告片 |

## 分镜与时间戳（多镜头叙事）

公式：提示词 = 总体描述 + 镜头序号 + 时间戳 + 分镜内容。
- 总体描述：一句话交代主题、视角、叙事风格与整体情绪。
- 时间戳：紧跟序号标起止；各镜头首尾相接、不跳段不重叠，**每段 2-5 秒**。
- 分镜内容：主体动作、台词、表情、场景细节；避免模型控不住的高频动作（如「一秒摇头3次」）。
- 格式不拘，通篇沿用一种：`第1个镜头[0-3秒]` / `分段1[0-5秒]：` / `分镜1（00:00-00:03）：` /
  只标序号 `镜头1：远景…` / 只标时间 `[00:00-00:03]`。

| 想实现什么 | 参考写法 |
|---|---|
| 单镜头不切分 | 首行写「生成单镜头」/「一镜到底」/ Generate single shot. |
| 镜头完全不动 | 固定镜头，摄影机静止，机位不变 |
| 指定运镜 | 大白话：推近、拉远、环绕、手持跟拍 |
| 镜头间转场 | 段末写「硬切转场」「叠化转场」，或下段开头「从上一分段的最后一帧无缝衔接」 |
| 强调节奏 | 总体描述补「节奏由沉稳压抑转为爆发」/「全片八个镜头，轻快铺垫、突发冲突、短促爆发、温暖收尾」 |
| 焦段/景深 | 85mm 长焦，浅景深 / 24mm 广角，深焦 |
| 高速摄影 | 高速摄影(1000fps 慢动作) |

## 台词

- 语法：角色 + 说话动词 + 冒号 + 引号内容。`xx说："内容"`、`她低语道："内容"`。
- 多人对话逐句标说话人：`图1说："xxxx"`；`图2回答："xxxx"`。
- 音色克隆：追加「音色参考 音频N」，写一次对该角色全部台词生效。
- 口型对齐：追加「口型同步」或 Lip sync.
- 旁白/独白同格式：`画外音："xxxx"`；`女声吟诵："xxxx"`。
- **不要台词必须显式写「无台词」或 No dialogue.**，否则模型自行决定加不加。

## 音效 / BGM

- 环境音自动匹配：画面写清动作、材质、气象（战旗猎猎/鼻息白气/积水踩踏），模型自动补音效。
- 指定音效单独成句，可带时间戳：`第 8 秒起，女声吟诵："xxxx"`、`色块滑入时'嗖'的 whoosh 声`。
- BGM 三档：
  1. 保守放开：什么都不写，模型自选。
  2. 明确指定：`BGM 转入低音区，大提琴以极轻力度缓缓加入`、`史诗交响+电子音效混合，节奏与镜头切换同步`。
  3. 完全不要：`无 bgm，只生成环境音和动作音` / No background music.

## 风格 / 情绪

画风+色调+情绪三件套，放开头或结尾均可。官方关键词参考：
- 画风：35mm电影胶片 / 港味写实 / 勾线插画 / 废土风格 / 宫崎骏动画 / 国风岩彩画 / 粘土动画 / motion graphics
- 色调：高饱和暖黄 / 青蓝×鎏金撞色 / 低调光高对比 / 环境去饱和青灰对比高饱和金色
- 情绪：悲壮孤峙 / 轻快治愈 / 压抑紧张 / 松弛自信 / 神秘魔幻

## 负向清单

只写不希望出现的内容；没有可留空，不凑数，不重复正向已写明的内容。

| 类别 | 常见项 |
|---|---|
| 人物/画面 | 不要人脸变形、不要人物换脸、不要多余手指、不要肢体扭曲、不要穿模变形、不要抠图痕迹、不要低清晰度 |
| 文字/水印 | 不要字幕、不要水印、不要复杂文字、不要额外品牌名称 |
| 风格 | 不要低幼卡通、不要写实真人风、不要游戏CG感、不要MV式炫技、不要现代高清数码感 |
| 声音 | 不要背景音乐、不要人声旁白、不要台词、不要背景音乐喧宾夺主 |
| 动作 | 不要人物无逻辑乱跑、不要夸张肢体动作、不要夸张眨眼、不要慢动作 |
| 运镜 | 不要大幅运镜、不要夸张镜头旋转、不要持续镜头抖动、不要频繁切镜 |
| 空间 | 不要空间混乱、不要轴线错乱、不要多人同屏 |
| 一致性 | 不要人物位置变化、不要服装变化、不要缩放漂移（编辑/参考场景常用） |

## 任务类型能力表（使用指南，输入→输出）

文生视频（单/多镜头叙事）；首帧生视频；首尾帧生视频；主体参考（锁外观/声音）；
运动参考（复刻动作/表情/运镜/特效）；风格参考；音频参考（音轨对齐）；白模参考/渲染；
多宫格分镜/故事板参考（按分镜剧情推演）；**关键帧参考（多张关键帧图对齐顺序）**；
文件/网页参考；视频指令编辑；视频参考图编辑；视频音频编辑；视频延长（前/后/双向）。

漫剧相关亮点：多宫格分镜图可直接当参考（一张图排多格分镜→按剧情推演视频）；
关键帧参考模式可把③阶段产出的多张关键帧按顺序对齐成一段视频——后续可试。

## 与 prompt_extend 的关系

官方：简短宽泛 prompt（「小猫在雪地里玩雪球」）开 prompt_extend 提升明显；
需要精准控制画面细节/风格/复杂动态时，用结构化公式手写，**关 prompt_extend 保意图**。
file/link 输入时 prompt_extend 强制 true（API 约束）。

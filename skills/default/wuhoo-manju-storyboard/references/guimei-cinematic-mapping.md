## 宿命感五要素（13 §1.2）→ 分镜设计检查项

1. 时间留白：对白与动作之间的沉默时长 → [驻留]/[静默] 记号
2. 空间留白：画面驻留/空旷构图/人物占比 → [孤悬构图]/大远景/人物占比小
3. 声音留白：环境渐弱/骤停/余响/音乐不进 → 声音组记号
4. 色彩变化：缓慢渐变而非切换 → [色变:…,N秒]
5. 重复意象：同一动作/话/声响复现 → [重复动作]/模式2回声

合成原则：宿命感最强=五要素同时在场；留白=蓄力，蓄力必释放（留白后必须有「声」或「变」）。
三基准：克制第一（拿不准删对白留画面）> 可标注第二 > 贯穿第三（宿命感是全书底色）。

## 29 五要素三镜结构（C档过场分镜定稿）

每镜头五要素：画面 / 时长 / 运动 / 色彩 / 声音。示例（超度金白·苏小小=钗落）：
```
镜1 她立中央微光浮起 2s 缓推 本色→金白 [磬单声]
镜2 金白爆亮全屏过曝 1s 定格 纯金白 [静]
镜3 鬼物志页亮名字浮现 2s 缓拉 金白→暖橙 [余响:磬3s]
```
8条24镜清单与 VD 卡对接见 29 原文；漫剧改编可直接复用 C 档分镜当镜头骨架。
生产纪律：每条 3-5 次 prompt 迭代预算；通用模板先做、内容层定制复用。

## 风格锚（决策110 + 40-shadow-puppet-direction）

- 皮影柔情国风 = 皮影部件工艺 × 剪纸东方 × 唱诗班表演 × 重彩志怪。
- 透光铁律：皮影透光=背光透射（灯在幕布后，光穿过半透明染色兽皮）→
  暖色/平面/色块/镂空透亮。**禁发光体语义**：glowing/neon/rim light三维描边光/
  sub-surface scattering/体积光。边缘暖金染光晕=透光染色，非描边光。
- 提示词风格段写法：「皮影戏美学，重彩志怪国风，剪纸镂空纹样，背光透射的暖色平面色块，
  幕布后灯影质感，矿物颜料重彩（朱砂/石青/石绿/鎏金），克制含蓄的东方叙事」。
- 色彩词典（06）：暖橙=人间/客栈；青绿=水/渡口阳面；冷翠=阴面/逢魔时；金白=超度。

## 08 对白纪律（台词进 prompt 前必查）

- 坐标：唐传奇对话（浅近文言+口语）与敦煌变文之间；可读性第一 > 时代感第二 > 文化密度第三。
- 浓度：L1鬼物志=文言笔记体；L2旁白=浅文；L3对白=口语+浅文；L4系统=白话。
- 对白内部：90% C2 人话 + 10% C3 环境句；**超度句/点题句锁 C2（六到十字人话）**。
  例：「这次……不用等了。」「西陵下，风停了。」
- 禁词25+：掌柜/大夫/姑娘/算了/谢谢/帮忙/爷爷/喝茶/睡觉/怎么/为什么/所以/但是/因为/
  然后/已经/还是/非常/真的/时候/地方/房间…（完整表见08原文，新写台词必跑 lint）。
- 语气词：吗呢吧啊哦嗯呃 → 么/罢/耶/喏/唔。
- 称呼：吴郎/吴生/郎君/守桥/阿翁（苏小小「妾/郎」断续歌谣感；镇民「吴郎」）。
- 中唐818-820语言基准；穿帮词17处已清（决策87）。

## 37 旁白纪律（漫剧画外音）

- 六通道分工：对白L3=情绪+关系+悬念；**旁白L2=剧情交代主通道**；环境叙事=背景世界观；
  鬼物志L1=档案知识；批注/留言簿=委托知识状态；系统L4=教学。
- 三问法则：玩家要知道发生了什么→旁白清楚交代；角色怎么想→留给玩家感受（含蓄）；
  现在不懂以后会懂→埋点不交代。
- 四类句：状态句（每场景开头1-2句）/目标句（章节开场1句）/身份句（关键人物首次出场1句）/
  因果句（关键事件后1句）。
- 三禁：禁上帝视角（「此时她心中百感交集」）/禁解释情绪（「她很难过」）/禁重复对白。
- 密度：每场景≤3句；语体=L2浅文+吴守桥视角（观察/转述/推断）。
- 视频提示词写法：`画外音（年轻男声，平静克制）："渡口的雾，比昨天重。"`

## 案例1：短剧·沈砚陆丰格斗（行业最佳实践，逐镜字段最细范本）

结构：主角图N/反派图N/场景图N → 风格 → **角色关系段**（体格差一眼可辨、各自打法逻辑）
→ **动作设计总则**（全片一条不中断的连贯格斗链，每一镜结束姿势=下一镜起始姿势，
站位/重心朝向/受力方向延续，不得瞬移不得凭空换位）→ 逐镜字段：

```
镜头N
时长：1.4秒
景别：中近景
摄像机角度：平视
运镜方式：横向慢移+呼吸感微晃
焦距与景深：中等景深
光线：侧逆光，高对比，暖橙+冷青
画面描述：…碰撞点/冲击波形态/介质层（尘埃白气）/破坏层（水渍细纹）/镜头反馈层（横移呼吸浮动）
背景音乐：低沉弦乐持续音+心跳低频
人声/音效：呼吸声（中心）/滴水声（环绕）/钢管刮擦（右声道）
镜头运动指令：由左向右极缓横移，尾帧停在两人正对构图
```

guimei  takeaway：逐镜字段可按需取用（景别/运镜/光线/声音必备；破坏层等打斗字段不用）；
「结束姿势=下一镜起始姿势」的连续性声明对多镜头一致性极有价值。

## 案例2：短剧·叶星辰洞府15s（固定空间关系范本）

结构：视频总时长/画幅比例/画风/核心剧情/对白（逐句标说话人）/图片引用/
**固定空间关系**（开头在洞府内景图4；中段叶星辰站门内偏左、女弟子站门外偏右，
面对面说话；最后一帧停在…）→ 逐段 0-2/2-4/…/14-15 秒 → **重要要求**
（两人必须是两个不同人物，不能共用同一张脸，不能长得像双胞胎；
不要出现宗门山门/圣地中心/交易会场景——负向场景排除；不要字幕/屏幕文字/背景音乐）。

guimei takeaway：多角色同框/对话镜头必写固定空间关系（谁左谁右、朝向、最后一帧停在哪）；
「不能共用同一张脸」硬声明直接抄；负向场景排除防模型乱入无关场景。

## 案例3：岩彩画西子15s（国风+定时旁白范本，与 guimei 最贴近）

结构：【一镜到底/运镜/时长/质感/撞色】题头 → **全局设定段**（画风质感+场景+主体完整描述：
鹅蛋脸柳叶眉丹凤眼眉心朱砂花钿、高挽发髻鎏金荷花簪、裙摆披帛由流动湖水构成）
→ **配音与音效段**（古筝竹笛+水波鸟鸣；**第8秒起**空灵温柔女声缓慢吟诵「欲把西湖比西子——」
回眸段接下半句「淡妆浓抹，总相宜。」语速缓慢带轻微回响余韵悠长）
→ 4个时间戳段（0-3一滴水/3-7水聚成形/7-11一步一莲/11-15回眸·总相宜），
每段内运镜中英双写（Tilt down/Orbit）、动作、旁白进入点、最后一秒定格海报构图。

guimei takeaway：国风美学描述的具体度标杆（矿物颜料颗粒肌理/金箔质感/青蓝鎏金撞色）；
**定时旁白**写法「第N秒起，音色描述+吟诵内容」直接用于苏小小歌谣/吴守桥旁白；
主体描述=面部+服饰+道具+质感四层，与 K2 母图锁定条款同构。

## 案例4：都市MG追逐30s（长时长多段+道具锁定范本）

结构：总述（30秒16:9+图N职责分工+「保持两人的脸、发型、体型、服装结构、配色和识别度稳定统一」）
→【整体风格】→【角色动作逻辑】（各自优势打法）→【光球】道具锁定
（一手可握白色核心紫粉蓝光晕，全片唯一争夺目标，真实照亮手脸边缘，
**始终只有一颗，大小稳定，不复制不消失不变形**，运动只有短促干净光轨）
→ 7个时间戳段（0-4/4-8/8-13/13-16.5/16.5-24/24-27.5/27.5-30，秒级小数切分）
→【负面限制】（不要平稳广告片镜头/不要慢动作/不要简单撕扯式抢球/不要人物变脸/
不要光球消失复制变形…）。

guimei takeaway：关键道具（钗子/珠串/纸灯）要写道具锁定段（数量/形态/不消失不变形）；
30s 内 7 段可行，段长可小数；一致性声明的标准句式出处。

## 案例5：蘑菇森林九宫格（纯时间戳多镜头 t2v 范本）

结构：7个时间戳段（0-2/2-4.5/4.5-7/7-9.5/9.5-12/12-14/14-15），每段=运镜+画面+动作+氛围；
结尾统一声明：**全程无字幕无人物对白**，仅环境音效动作音效；配乐三段情绪
（开篇轻松温暖舒缓→异变骤转紧张弦乐→逃亡急促打击乐→结尾安静仅呼吸声）；
画风质感声明（皮克斯3D/8K/16:9/复合运镜）；负向（禁止真人实拍/写实皮肤纹理/2D手绘平涂/
日式动漫/任何可读文字字幕水印）。

guimei takeaway：无对白片的声明写法；BGM 情绪分段声明（guimei 用「无铺底BGM+指定时刻磬声」反向用法）；
时间戳段不需要序号也能工作（纯时间戳格式官方认可）。

## 案例6：唐人街功夫25s8镜（多主体锁定+节奏总谱范本）

结构：总体描述（题材+风格+色调+情绪走向+**全片二十五秒八个镜头，节奏为轻快铺垫、
突发冲突、短促爆发、温暖收尾**+表演总则「真实有重量感，不要游戏CG感不要MV式炫技」）
→ **主体锁定段**（小女孩图6、棒棒糖图7、小流氓图4…逐个图N映射）→ 场景细节段
→ 镜头01-08（每镜=景别+运镜+焦段+画面+台词+声音层）。

guimei takeaway：节奏总谱写进总体描述（guimei 六镜「静蓄力→微动留白→声起释放→
色变释放→世界活了→终极释放归静」即此用法）；t2v 无图N时主体锁定段改为纯文本外貌描述。

## 案例7：水墨竹林首帧+多镜头（i2v 也能多镜头时间戳）

首帧图承载风格，prompt 用（0:00-0:03）（0:03-0:08）…5段时间戳，
每段=运镜/画面/动作/氛围/细节，结尾风格说明「整个过程保持图1的高度黑白水墨画风格」。
证明多镜头时间戳叙事在 i2v 分支同样可用（可选分支升级方向：母图首帧+多镜头时间戳）。

## 故事板/多宫格参考（官方规则）

- 开头声明用途：「使用故事板作为分镜指导，禁止将故事板作为单张图像生成视频」
- 逐格重述：左上到右下顺序描述各格景别/运镜/主体位置；格内未体现的环境光线粒子由提示词补
- 分段无需与宫格一一对应（故事板仅为剧情梗概）
- 结尾统一声明画风/渲染质感/画幅+负向排除干扰画风
- guimei 用法展望：分镜表画成九宫格故事板图作 reference_image，可能是比纯文本更强的
  构图控制手段（待后续测试，本轮主路线为纯文本 t2v）。

## 结构共性总结（guimei 多镜头模板的依据）

1. 三层锁定：角色外貌锁定 + 固定空间关系 + 关键道具锁定（数量/形态/不消失）。
2. 一致性硬声明：不同角色不共用同一张脸；跨镜头脸/发型/服装结构/配色稳定统一；
   连续性（上一镜结束姿势=下一镜起始姿势，不得瞬移）。
3. 节奏总谱进总体描述；逐段时间戳首尾相接；段内=景别+运镜+画面+台词+声音+色彩+转场。
4. 定时台词/旁白：「第N秒起，音色描述+内容」；无台词显式声明。
5. 声音分层：环境音（靠画面动作材质自动匹配）+指定音效（单独成句可带时间戳）+BGM三档。
6. 负向清单分类写：人物/画面/文字水印/风格/声音/动作/运镜/空间/一致性/场景排除。

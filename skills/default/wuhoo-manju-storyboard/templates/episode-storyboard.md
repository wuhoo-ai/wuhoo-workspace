# 漫剧立项单 + 分镜脚本表模板

> 复制本模板到 games/guimei/manju/<YYYY-MM-DD>-<章节slug>/，占位符全部替换。
> 事实源=GDD 定稿剧本；台词/旁白逐字照录；新增情节须用户拍板。

## 一、立项单（episode-plan.md）

```markdown
# 漫剧立项：<集名>
> 日期: <YYYY-MM-DD> | 源: GDD/chapters/<chapter文件> <场景号范围>
> 状态: 草稿/待拍板/已确认

## 情感弧（一句话）
<例：等了三百年的人，第一次被告知「不用等了」。>

## 选段理由
- 情感节拍: <完整弧？起承转合落点>
- 视觉招牌: <雾/灯/钗/梳头/色变…>
- 资产就绪: <哪些角色有标杆图，哪些需新出关键帧>

## 规格
- 画幅: 竖屏 9:16（首帧竖构图 + ratio adaptive）/ 横屏 16:9
- 镜头数: <N>（1-2分钟≈8-15镜；每镜2-5s）
- 总时长预算: <N>s
- 试产镜头: <镜号>（选择理由：资产就绪/低运动风险/无台词）
- 试产参数: 5s / 720P / wan3.0-video-prime(回退标准版) / audio=true / prompt_extend=false

## 角色资产清单
| 角色 | 标杆图路径 | 族系特征锁定句 | 本集镜头 |
|---|---|---|---|
| <名> | <review/…或art-samples/…> | <发色/结饰/衣制/磷光…> | <镜号> |

## 预算
- 每镜头 3-5 次 prompt 迭代（29纪律）；试产 1 镜 5s/720P ≈ $0.70 等值 Credits
- 超预算停下复盘，不无限烧
```

## 二、分镜脚本表（storyboard.md）

```markdown
# 分镜脚本：<集名>
> 13记号原样保留；④阶段翻译成提示词（映射表见技能 references/guimei-cinematic-mapping.md）

| 镜号 | 源场景 | 景别 | 运镜 | 时长 | 画面(主体+场景+运动) | 色彩 | 声音 | 台词/旁白(逐字) | 转场 | 资产依赖 |
|---|---|---|---|---|---|---|---|---|---|---|
| 01 | S2 | 大远景 | 固定 | 4s | < fog中渡口废墟全貌，晾衣绳空晃 > | [色:青绿雾] | [环境:风声水声] | 画外音:"<状态句>" | 硬切 | 场景关键帧 |
| 02 | S6 | 中近景 | 缓推 | 5s | <苏小小船头梳头，一下一下> | [色:冷翠+腰間暗红] | [环境渐弱→静] | 无台词 | 叠化 | 苏小小关键帧 |
| … | | | | | | | | | | |

## 节奏总谱
<例：静(01-02)→微动(03)→声起(04)→色变释放(05)→留白收(06)；留白=蓄力，蓄力必释放>

## 忠实性自查
- [ ] 每句台词/旁白能在 GDD 原文找到出处（逐字含标点）
- [ ] 无新增情节/人物/道具（有→标「待拍板」）
- [ ] 旁白每场景≤3句，三禁（上帝视角/解释情绪/重复对白）
- [ ] 新写台词过08禁词lint（照录GDD的免查）
- [ ] 宿命感五要素至少占其一/镜头
- [ ] 高频动作零出现（一秒N次类）
```

# 多镜头 t2v 提示词模板（主路线）

> 依据：官方公式（wan3-prompt-formula.md）+ 经典案例结构共性（classic-cases.md）。
> 参数（resolution/ratio/duration/audio/seed）不进正文，写参数单。prompt_extend=false。
> 实例参考：games/guimei/manju/2026-11-17-ch01-ferry/t2v-test/ch01-multishot-prompt.txt

```text
<项目/章节>漫剧<teaser/正片>，竖屏9:16，全片<N>秒，<M>个镜头，硬切与叠化转场按各镜头标注。
<风格美学总述：皮影柔情国风志怪——皮影部件工艺，半透明牛皮材质背光透光染色（暖色平面色块、
剪纸镂空纹样、关节分层接缝部件可拆感），剪纸东方构成，水墨重彩志怪，矿物颜料重彩色谱
（冷翠/青绿/朱红/纸白/墨黑/暖橙/金白）。克制含蓄，哀而不伤，宿命感：留白是蓄力，蓄力必释放。>
节奏：<节奏总谱，如 静蓄力→微动留白→声起释放→色变释放→世界活了→终极释放归静>。
角色跨镜头保持一致：<角色A>与<角色B>是两个不同角色，不能共用同一张脸，各自的脸色、发型、
服装结构、配色与识别度全片稳定统一，不要服装漂移，不要换脸。
<角色A>=<完整外貌文本锁定：骨相/发型头饰/服装形制与配色/道具/灵体质感，按母图实际外观
或GDD角色表逐条写死；手部五指并拢可读+单手势>。
<角色B>=<同上>。
关键道具锁定：<道具数量/形态/颜色，始终只有一件，不复制不消失不变形>。
面部按现代审美写实刻画（立体光影、真实皮肤质感、有情绪的眼神），水墨重彩风格只作用于
服装背景氛围不作用于面部。
镜头1（0-<a>秒）：<景别+运镜（大白话+焦段可选）>，<色彩>。<画面：主体动作+场景细节+
空间关系+美学控制>。<台词：角色说/低语道："逐字原文" / 画外音（音色描述）："逐字原文" /
第N秒起… / 无台词>。声音：<环境音（写清材质动作）+指定音效单独成句>。<转场：硬切转场/叠化转场>。
镜头2（<a>-<b>秒）：…
…
镜头M（<x>-<N>秒）：…<最后一帧停在哪/渐暗黑场>。
风格情绪：<画风+色调+情绪三件套>。全片环境音为主，无铺底BGM，只在指定时刻进<磬声/钗落声>。
负向清单：无字幕水印，无现代元素，不要写实真人风，不要日系动漫，不要低幼卡通，
不要3D渲染塑料感，不要人脸变形，不要人物换脸，不要多余手指，不要肢体扭曲，不要穿模，
不要夸张运镜，不要夸张眨眼，不要霓虹发光体，不要三维描边光，不要人物位置无故变化，
不要服装变化，不要多余人物，不要背景音乐喧宾夺主<+场景排除项>。
```

## 参数单（随提示词配对归档）

```
model: wan3.0-video-prime（被拒自动回退 wan3.0-video）
resolution: 720P（试产）/1080P（定稿）
ratio: 9:16（t2v 直传已实证被接受）
duration: <总时长，≤30>
audio: true（原生台词+环境音）
prompt_extend: false
seed: 随机（记录于 sidecar）
预算: <N>s×720P≈$0.14/s 等值 Credits；本批次≤3-5次迭代
```

## 检查清单（投喂前自查）

- [ ] 时间戳首尾相接不跳段不重叠，总和=duration
- [ ] 每句台词/旁白能在 GDD 原文找到出处（逐字含标点）
- [ ] 每个出场角色有完整文本锁定段；多角色有「不共用同一张脸」声明
- [ ] 关键道具有锁定段（数量/形态/不消失）
- [ ] 无台词镜头显式写「无台词」
- [ ] 13 记号已翻译（驻留/色变/单声/环境渐弱…见 guimei-cinematic-mapping.md）
- [ ] 透光=背光透射表述+负向禁发光体
- [ ] 参数不在正文；prompt_extend=false
- [ ] 高频动作零出现；新写台词过 08 禁词 lint

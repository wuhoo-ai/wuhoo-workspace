## ① 选段立项

- 一集漫剧 = 一个情感弧，不是整章。1-2 分钟 ≈ 8-15 个分镜（业界经验）；
  wan3.0 单次生成 ≤30s，一集可多次生成后 ffmpeg 拼接，或 30s 内做 teaser。
- 选段标准：情感节拍完整（如第一章「苏小小·渡」弧）、视觉招牌强（雾/灯/钗/梳头）。
- 立项单写明：源章节+场景号、情感弧一句话、镜头数与总时长、角色清单、生成批次划分。
- 章节选择属实现细节可自定，但**改动 GDD 剧情事实=设计基调，必须用户拍板**。

## ② 分镜拆解（画面清单）

每镜头一行，字段继承 29 定稿五要素（画面/时长/运动/色彩/声音）+ 13 记号：

```
镜号 | 源场景 | 景别 | 运镜 | 时长 | 画面(主体+场景+运动) | 色彩 | 声音 | 台词/旁白(逐字) | 转场
```

纪律：
- **忠实 GDD**：台词/旁白逐字照录（含标点断句，如「油壁车……夕相待。」「人不来……」），
  不扩写剧情、不加 GDD 没有的情节（wan3-pe 忠实性硬约束，见 references/wan3-pe-format.md）。
- **克制第一**（13 三基准）：拿不准时删对白留画面；留白是设计不是空洞——
  宿命感五要素（时间/空间/声音留白+色彩渐变+重复意象）至少占其一。
- 旁白按 37 规范：吴守桥视角 L2 浅文，四类句（状态/目标/身份/因果），每场景≤3句，
  三禁（上帝视角/解释情绪/重复对白）。
- 13 记号原样保留在分镜表，③阶段翻译成提示词语言（映射表见 references/guimei-cinematic-mapping.md）。
- 景别/运镜用大白话+焦段（「大远景建立镜头，24mm广角，极低角度仰拍，摄影机静止」），
  避免模型控不住的高频动作（「一秒摇头3次」禁写）。
- 时间戳首尾相接不跳段不重叠，每段 2-5s 为宜（官方推荐，6-8s 段案例也存在）；
  转场写「硬切转场/叠化转场/从上一分段最后一帧无缝衔接」。

## ③ 多镜头 t2v 提示词成型（核心工序）

结构模板（官方公式 + 经典案例结构，详见 templates/multishot-t2v.md 与 references/classic-cases.md）：

```
[总体描述] 题材+画幅+总时长+镜头数+风格美学+情绪基调+节奏总谱
[角色文本锁定段] 每个角色完整外貌描述（t2v 无参考图，文本即唯一一致性来源）：
  骨相/发型/服装形制与配色/道具/灵体质感——按母图实际外观或 GDD 角色表逐条写死
[一致性声明] 「角色跨镜头保持一致：A与B是两个不同角色，不能共用同一张脸，
  各自的脸色、发型、服装结构、配色与识别度全片稳定统一，不要服装漂移，不要换脸」
[镜头N（起-止秒）] 景别+运镜+画面(主体动作+场景细节+美学控制)+台词(逐字)+声音+色彩变化+转场
[风格情绪段] 画风+色调+情绪三件套
[负向清单] 只写排除项，不凑数
```

- **角色文本锁定是 t2v 一致性的命门**：描述越具体越稳（「一只猫」不如「橘色短毛猫」）；
  族系特征（发色/结饰/磷光/衣制）逐条写；手部「五指并拢可读」+单手势；
  物件-场景空间关系显式（「鱼在网内」不是「鱼和网」）——K2 已验证对策。
- 台词语法：`她低语道："……"`；旁白 `画外音（音色描述）："……"`；
  定时台词学西子案例「第8秒起，女声吟诵：……」；无台词镜头显式写「无台词」。
  原生音频自动生成台词人声，口型/音色质量由人工审核判定，不满意走后期配音（34配音规范）。
- BGM 三档：不写=模型自选；指定=写清乐器/力度/进入时刻；不要=「无bgm，只生成环境音和动作音」。
  guimei 默认保守：环境音为主，超度/点题时刻才进「一声磬」类指定音效（11 声音词典）。
- 13 记号翻译：[缓推]→「镜头缓慢推近」；[驻留Ns]→「画面驻留N秒，主体近乎静止，仅呼吸级微动」；
  [色变:A→B,N秒]→「色调在N秒内从A缓慢渐变为B（渐变不是切换）」；[环境渐弱→静]→「环境声渐弱至静默」。
- 风格锚：皮影柔情国风（决策110）= 皮影部件工艺×剪纸东方×唱诗班表演×重彩志怪；
  透光=背光透射（暖色/平面/色块/镂空透亮），**禁发光体语义**（glowing/neon/rim light/体积光）；
  面部现代审美写实、风格只作用于服装背景氛围（K2 母图已验证的脸部处理条款）。
- **参数分离**：resolution/ratio/duration/audio/seed 写进参数单，不写进 prompt 正文
  （时间戳属创作内容保留在正文）。prompt_extend=false（精细分镜保意图）。
- 可选五段式重组（wan3-pe【核心任务】【情节概要】【音频风格】【运镜与核心约束】【负面提示词】），
  多素材复杂请求时用；纯 t2v 多镜头直写上述结构即可。

## ④ 试产（wuhoo-video-generation 技能）

```bash
S=~/wuhoo-workspace/skills/shared/wuhoo-video-generation/gen_video.py
# 多镜头 t2v 直出（主路线）
python3.11 $S --prompt "$(cat <提示词txt>)" \
  --resolution 720P --duration 30 --ratio 9:16 --no-prompt-extend \
  --submit-only --output <目录>/<名>.mp4
# 拿 task_id 后有界续查下载
python3.11 $S --task-id <id> --output <目录>/<名>.mp4
```

- 竖屏：**t2v 直传 ratio=9:16 已被 API 接受**（11-18 task 0f7534fe 实证）；
  i2v 分支用 adaptive+竖构图首帧（输出自动 9:16）。
- 模型默认 wan3.0-video-prime，cn-beijing 实测可调（catalog 未列但提交成功）；
  被拒自动回退 wan3.0-video。30s/720P prime 实测 ≈3min17s。
- 预算：5s/720P≈$0.70 等值，30s/720P≈$4.2 等值（国际站公示价参考，cn-beijing 按 Credits）。
  每批次 3-5 次 prompt 迭代预算（29 纪律）；超预算停下复盘，不无限烧。
- 长任务纪律：--submit-only + 有界续查；task_id 与 video_url 均 24h 有效，当天下载归档。

## ⑤ 验收：人工审核终闸 + 辅助指标

1. **人工审核（用户）= 唯一最终闸**。交付物摆到用户面前：成片 + 完整提示词 + 参数单。
   审核焦点提示（供用户参考，不替用户下结论）：角色跨镜头一致（换脸/服装漂移）、
   面部手部、时间戳分镜是否被正确执行、台词人声质量、色变渐变、透光语义、穿帮。
2. 辅助指标（零成本，供审核参考，不作闸）：
   - sidecar JSON（task_id/model_used/usage）+ ffprobe（分辨率/帧率/时长/音轨）
   - frame_diff（guimei 仓 tools/frame_diff.py）：真动画/假动画、能量分布
   - 抽帧接触表（ffmpeg 抽帧 + PIL 拼条）方便用户快速扫视
3. 审核 FAIL → 记录用户意见原文 → 定位到提示词具体段落修改 → 重投（迭代记录留档）。
   不再跑 vision LLM 审计（用户 11-18 拍板撤销）。

## Pitfalls

- **多镜头一致性是 t2v 的核心风险**：文本锁定+一致性声明必写；审核重点看跨镜头换脸/
  服装漂移/道具变形。官方短剧案例用「固定空间关系」「两人不能共用同一张脸」类硬声明，学它。
- **台词风险**：原生音频自动生成人声，音色/口型/断句质量不稳定是预期内；
  审核不满意 → 画面保留 + 后期配音（34 配音规范）双轨，不无限重烧视频。
- **高动态镜头**：爆亮过曝/大幅色变属高风险演出，prompt 写「渐变不是切换」，
  审核不过可拆段生成再 ffmpeg 拼接。
- **ratio 文档分歧已实证**：API 参考表列 5 值，使用指南列 7 值（含 3:4/9:16）；
  t2v 直传 9:16 实测被接受（11-18）。以实际提交为准，catalog/文档表都会滞后。
- **禁词穿帮**：台词照录 GDD 已过 lint 的原文；新写台词必跑 08 禁词检查
  （掌柜/姑娘/谢谢/怎么/为什么/已经…25+禁词；语气词用么/罢/耶/喏/唔）。
- **项目名只写 guimei**：禁止自造中文名（用户铁律）；GDD 原文注释性别称不改不传。
- **发光体语义污染**：wan 系模型爱把「透光」画成 neon/rim light；prompt 必须写
  「背光透射、暖色平面色块、镂空透亮」并在负向清单禁发光体。
- **旁白抢戏**：旁白是吴守桥的「看见」不是解说员；每场景≤3句，删对白留画面优先。
- **prompt_extend 会改写意图**：精细分镜默认关；只有 file/link 模式强制 true。
- **同 seed 不逐帧确定**：复现靠 prompt.md+参数单+原片归档，不靠 seed。
- （可选工具坑）vision_analyze 间歇路由错误（qwen4-max 被发 deepseek-only 端点）：
  如需抽帧送审，图转 JPEG q85-92 小图；大 PNG base64 直传会 WriteTimeout。
  主路线已不依赖 vision 审计。

# 快速诊断报告模板

> 适用于用户直接提供持仓数据（WeChat/CLI）的诊断场景。
> 数据源：用户持仓 + akshare K线 + web_search 基本面。

## 报告结构

### ⚠️ 一、组合级风险警示（表格 + 信号灯）

```
| 维度 | 数据 | 风险等级 |
|------|------|:---:|
| 行业集中度 | xx%同一产业链 | 🔴 |
| 单只最大仓位 | xx% | 🔴🔴 |
| Top-N 集中度 | xx% | 🟡 |
| 近N日组合回撤 | -xx% | 🟡 |
| 现金比率 | xx% | 🟢 |
```

**关键风险用红色标注**，如"锂电产业链集中度84%"、"48%单票超标"。

### 📊 二、逐只个股多空辩论 + 技术面分析

每只股票一个独立区块：

```
### N️⃣ 股票名 (代码) — 风险图标 一句话定性

| 指标 | 数值 | 信号 |
|------|------|:---:|
| 成本/现价 | xx / xx | 📉/📈 ±xx% |
| 持仓市值/占比 | xx万 / xx% | 信号灯 |
| 5日/10日/20日动量 | ±xx% / ±xx% / ±xx% | 信号 |
| RSI(14) | xx | 信号 |
| 波动率(20日年化) | xx% | 信号 |
| Q1关键财务 | xx | 信号 |

🐂 多头逻辑（3-5条，bullet list）
🐻 空头逻辑（3-5条，bullet list）
🎯 辩论结论：**BUY/SELL/HOLD** + 一句话总结
```

### 📋 三、组合风险矩阵

```
| 风险类型 | 等级 | 说明 |
|----------|:---:|------|
| 行业集中度 | 🔴🔴 | 说明 |
| 单票集中度 | 🔴 | 说明 |
| 波动率风险 | 🔴 | 说明 |
| 流动性风险 | — | 说明 |
| 政策风险 | 🟡 | 说明 |
```

### 🎯 四、调仓建议

核心逻辑（一句话）+ 操作表格：

```
| 股票 | 现仓位 | 操作 | 建议仓位 | 操作理由 |
|------|:---:|:---:|:---:|------|
| xxx | xx% | 🔴/🟡/🟢 操作 | xx% | 理由 |
```

### ⏱️ 执行优先级

分优先级列出具体操作（卖多少股、买多少股、止损价、目标仓位）。

### 📋 五、关键监控指标

3-5条监控规则（什么条件下触发什么操作）。

## 信号灯约定

| 图标 | 含义 |
|:---:|------|
| 🔴🔴 | 严重超标，必须立即处理 |
| 🔴 | 风险偏高，需要关注/减仓 |
| 🟡 | 中性/需要观察 |
| 🟢 | 健康，可维持或加仓 |

## 调仓信号约定

| 信号 | 含义 | 典型触发 |
|------|------|----------|
| **CLEAR** | 清仓 | 亏损>15% 或 基本面恶化 |
| **REDUCE** | 减仓 | 集中度超标 或 亏损>8% 或 技术面破位 |
| **HOLD** | 持有观察 | 仓位合理+信号中性 |
| **ADD** | 加仓 | 强基本面+低仓位+技术面回调到位 |

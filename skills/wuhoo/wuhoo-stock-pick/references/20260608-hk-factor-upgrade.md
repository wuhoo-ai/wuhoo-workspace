# 2026-06-08 港股因子全面升级

## 背景
原港股选股使用 2 因子简化模型（波动率 + 动量），通过 Futu OpenD `request_history_kline` 逐只获取 500 只 K 线。

## 问题
1. **数据覆盖仅 5%**: Futu API 逐只调用，大部分静默失败，最终仅 25/500 只有效
2. **银行垄断**: 波动率 <25.84 硬阈值过滤所有科技股（波动率 35-55%），仅银行（19-25%）通过
3. **因子不足**: 缺少换手率、Beta、残差波动率

## 修复
- `calculate_factors_simple(market='hk')` 重写为 yfinance + ^HSI 5 因子模型
- `yf.download()` 批量下载，20 只/批，重试容错
- 结果: 25/500 → **492/500 (98.4%)**

## 验证
- 修复前: 4 银行
- 修复后: 8 只/7 行业（汽车/地产/电信/工业/科技），0 银行

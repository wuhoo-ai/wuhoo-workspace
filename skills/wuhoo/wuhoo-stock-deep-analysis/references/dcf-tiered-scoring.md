# DCF 三情景分层评分规则（2026-06-08）

`_make_final_decision()` 估值维度不再使用单一 `margin_of_safety`，改为按 DCF 三情景逐情景计算安全边际。

## 计算公式

```
mos = (current_price - value_per_share) / value_per_share * 100
```
- 正值 = 当前价格高于内在价值（溢价/高估）
- 负值 = 当前价格低于内在价值（折价/低估）

## 评分规则

| 条件 | 得分 | 含义 |
|------|------|------|
| 三情景全正安全边际（current < iv） | +2.0 | DCF 极度低估 |
| 两情景正 | +1.5 | DCF 合理低估 |
| 仅乐观情景正 | +0.5 | 仅乐观情景有安全边际 |
| 全负，乐观溢价 < 30% | 0 | 乐观情景接近合理价 |
| 全负，乐观溢价 30-100% | -0.5 | 温和高估 |
| 全负，乐观溢价 > 100% | -1.5 | 严重高估 |

## 效果对比

| 股票 | 溢价（乐观）| 旧得分 | 新得分 | 决策变化 |
|------|-----------|--------|--------|---------|
| 鸿远电子 603267 | 29.4% | -1.5 | 0 | 卖出→持有 |
| 富乐德 301297 | 47% | -1.5 | -0.5 | 强烈卖出1.0→3.0 |
| 昌红科技 300151 | 294% | -1.5 | -1.5 | 不变（仍扣满） |

## 降级

当 `scenarios` 不可用时，回退到旧的单一 `margin_of_safety` 判断（>30% +1.5, 0-30% +0.5, <-20% -1.5）。

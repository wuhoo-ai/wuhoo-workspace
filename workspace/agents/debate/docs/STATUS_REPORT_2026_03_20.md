**问题**: `review()` 方法参数名不一致

```python
# 当前实现
def review(self, symbol, trader_decision, portfolio_state)

# 调用代码使用
risk.review(symbol=symbol, action=trader_decision, ...)  # ❌ 参数名错误
```

**修复方案**:
```python
# 方案 A: 修改方法签名 (推荐)
def review(self, symbol, action, portfolio_state)

# 方案 B: 添加别名
def review(self, symbol, trader_decision=None, action=None, portfolio_state):
    decision = action or trader_decision
```

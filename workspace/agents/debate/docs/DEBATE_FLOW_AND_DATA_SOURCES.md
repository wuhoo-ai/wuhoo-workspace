## 🔍 阶段 1: 数据加载详解

### DataAggregator 接口

```python
aggregator = DataAggregator()
data = aggregator.get_all_data(symbol, name)

# 返回数据结构
{
    "factor_data": {...},      # 因子评分
    "technical_data": {...},   # 技术面指标
    "sentiment_data": {...},   # 舆情数据
    "fundamental_data": {...}  # 基本面数据
}
```

### 数据源 1: QuantaAlpha (因子数据)

**适配器**: `adapters/quantaalpha_adapter.py`

**提供数据**:
| 数据类型 | 字段 | 说明 |
|---------|------|------|
| 动量评分 | `momentum_score` | 20 日/60 日动量因子综合 |
| 波动率评分 | `volatility_score` | 5 日/20 日波动率因子 |
| 量价评分 | `price_volume_score` | 量价关系因子 |
| 反转评分 | `reversal_score` | 短期反转信号 |
| 综合评分 | `composite_score` | 多因子加权 |

**获取方式**:
```python
adapter = QuantaAlphaAdapter()
scores = adapter.get_factor_scores("600519.SH")
```

**数据更新频率**: 实时 (基于最新行情)

**覆盖范围**: A 股全市场 (6000+ 股票)

---

### 数据源 2: AkShare (技术面 + 基本面)

**适配器**: `adapters/akshare_adapter.py`

**技术面数据**:
| 指标 | 字段 | 说明 |
|------|------|------|
| MACD | `macd`, `macd_signal`, `macd_hist` | 趋势指标 |
| RSI | `rsi_6`, `rsi_12`, `rsi_24` | 超买超卖 |
| KDJ | `k`, `d`, `j` | 随机指标 |
| 布林带 | `boll_upper`, `boll_mid`, `boll_lower` | 波动区间 |
| 均线 | `ma5`, `ma10`, `ma20`, `ma60` | 移动平均 |
| 成交量 | `volume`, `volume_ma` | 量能分析 |
| 资金流 | `main_force_in`, `north_bound_in` | 主力/北向 |

**基本面数据**:
| 指标 | 字段 | 说明 |
|------|------|------|
| 估值 | `pe`, `pb`, `ps` | PE/PB/PS |
| 成长 | `revenue_growth`, `profit_growth` | 营收/利润增速 |
| 盈利 | `roe`, `roa`, `gross_margin` | ROE/ROA/毛利率 |
| 负债 | `debt_ratio`, `current_ratio` | 负债率/流动比率 |

**获取方式**:
```python
adapter = AkShareAdapter()
technical = adapter.get_technical_data("600519.SH")
fundamental = adapter.get_fundamental_data("600519.SH")
```

**数据更新频率**: 
- 技术面：实时 (交易时间内)
- 基本面：季度 (财报发布后)

**安装**: 
```bash
python3.11 -m venv venv
source venv/bin/activate
pip install akshare
```

## 🐂🐻 阶段 2: 多空辩论详解

### Bull Agent 分析流程

```
输入：因子数据 + 技术面 + 舆情 + 基本面
         ↓
1. 识别利好信号
   • 因子评分 > 阈值
   • 技术面金叉/突破
   • 舆情正面
   • 基本面改善
         ↓
2. 评估信号强度
   • 多个信号共振 → 高置信度
   • 单一信号 → 低置信度
         ↓
3. 生成看多理由
   • 列出 3-5 个关键论点
   • 每个论点附带数据支撑
         ↓
4. 输出推荐
   • BUY / HOLD
   • 置信度 (0-1)
   • 目标价
   • 风险因素
```

**Prompt 模板**: `prompts/bull_analyst.md`

**输出示例**:
```json
{
  "recommendation": "BUY",
  "confidence": 0.72,
  "key_points": [
    "20 日动量因子评分 0.85，处于历史高位",
    "MACD 金叉，RSI 55 处于强势区",
    "北向资金连续 3 日净流入",
    "Q3 营收同比增长 25%，超预期"
  ],
  "target_price": 2000,
  "risks": ["市场整体回调风险", "行业政策不确定性"]
}
```

---

### Bear Agent 分析流程

```
输入：因子数据 + 技术面 + 舆情 + 基本面 + Bull 观点
         ↓
1. 识别利空信号
   • 因子评分 < 阈值
   • 技术面死叉/破位
   • 舆情负面
   • 基本面恶化
         ↓
2. 反驳 Bull 观点
   • 逐条分析 Bull 论点的漏洞
   • 提供反面证据
         ↓
3. 评估风险因素
   • 估值过高
   • 行业周期下行
   • 政策风险
         ↓
4. 输出推荐
   • SELL / HOLD
   • 置信度 (0-1)
   • 止损价
   • 反驳论点
```

**Prompt 模板**: `prompts/bear_analyst.md`

**输出示例**:
```json
{
  "recommendation": "SELL",
  "confidence": 0.68,
  "key_points": [
    "当前 PE 65x，处于历史 90% 分位",
    "布林带上轨突破，但成交量萎缩",
    "行业竞争加剧，毛利率承压"
  ],
  "rebuttals": [
    "Bull 提到的动量因子虽高，但已出现背离",
    "北向资金流入但主力净流出"
  ],
  "stop_loss": 1800
}
```

## 📊 阶段 3: 辩论分析详解

### DebateProtocol 职责

```python
protocol = DebateProtocol()
protocol.start_debate(symbol)
protocol.submit_bull_view(bull_view)
protocol.submit_bear_view(bear_view)
analysis = protocol.analyze_debate()
```

### 分析维度

| 维度 | 说明 | 提取方法 |
|------|------|---------|
| **共识点** | 双方都认同的观点 | 语义相似度 > 0.8 |
| **分歧点** | 双方观点冲突 | 推荐方向/目标价差异 |
| **关键争议** | 核心分歧焦点 | 置信度差异最大的论点 |
| **证据强度对比** | 多空双方数据支撑 | 论据数量 + 数据质量 |

### 输出示例

```json
{
  "consensus": [
    "双方都认同需要设置止损",
    "双方都认为 Q3 财报是关键催化剂"
  ],
  "disagreements": [
    "推荐方向分歧 (BUY vs SELL)",
    "目标价分歧较大 (29.6%)"
  ],
  "key_contentions": [
    "估值合理性：Bull 认为合理 vs Bear 认为高估",
    "技术面解读：Bull 看突破 vs Bear 看背离"
  ],
  "bull_evidence_strength": 0.72,
  "bear_evidence_strength": 0.68
}
```

## 💼 阶段 4: 交易决策详解

### Trader Agent 决策矩阵

| Bull 置信度 | Bear 置信度 | 证据强度差 | 决策 |
|-----------|-----------|-----------|------|
| >0.7 | <0.5 | >0.2 | **BUY** (高置信) |
| >0.6 | <0.5 | >0.1 | **BUY** (中置信) |
| <0.5 | >0.7 | >0.2 | **SELL** (高置信) |
| <0.5 | >0.6 | >0.1 | **SELL** (中置信) |
| 差值<0.1 | - | - | **HOLD** (观望) |

## 🛡️ 阶段 5: 风控审核详解

### Risk Agent 检查清单

| 检查项 | 规则 | 阈值 |
|--------|------|------|
| **止损检查** | 止损幅度 | ≤8% |
| **仓位检查** | 单只股票仓位 | ≤20% |
| **风险收益比** | 上行/下行 | ≥2.0 |
| **波动性检查** | 20 日波动率 | ≤30% |
| **流动性检查** | 日均成交额 | ≥1 亿 |

### 审批结果

| 审批 | 条件 |
|------|------|
| **APPROVE** | 所有检查通过，风险评分<0.4 |
| **CONDITIONAL** | 部分检查未通过，需附加条件 |
| **REJECT** | 关键检查失败，风险评分>0.7 |

## 📋 阶段 6: 最终审批详解

### Portfolio Manager 职责

1. **组合层面评估**
   - 行业集中度
   - 整体风险暴露
   - 现金比例

2. **用户确认** (可选)
   - 高风险交易需用户确认
   - 大额交易需用户确认

3. **执行决策**
   - APPROVED → 执行交易
   - REJECTED → 暂缓/拒绝

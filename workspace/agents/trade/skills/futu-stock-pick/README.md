# 港股/美股选股工具 - 快速使用指南

## 🚀 快速开始

### 港股选股 (恒生指数成分股)

```bash
cd ~/.openclaw/workspace/agents/trade/skills/futu-stock-pick

# 激活虚拟环境
source ~/.openclaw/workspace/agents/trade/venv-futu/bin/activate

# 运行选股
python futu_stock_pick.py --market HK --index HS --top-n 10
```

### 美股选股 (标普 500 成分股)

```bash
python futu_stock_pick.py --market US --index SPX --top-n 10
```

## 🔧 参数说明

```bash
python futu_stock_pick.py \
  --market HK \              # 市场：HK/US
  --index HS \               # 指数代码
  --top-n 10 \               # 输出数量
  --host 127.0.0.1 \         # OpenD 主机
  --port 11111               # OpenD 端口
```

---

## ⚠️ 注意事项

1. **OpenD 必须运行**: 确保富途 OpenD 已启动并监听 11111 端口
2. **行情权限**: 需要富途行情权限
3. **数据限制**: API 有调用频率限制，大批量选股需要时间
4. **成分股数量**: 部分指数成分股获取可能受限

---

## 🛠️ 故障处理

| 问题 | 解决方案 |
|------|----------|
| 连接失败 | 检查 OpenD 是否运行 |
| 成分股数量为 0 | 检查指数代码是否正确 |
| API 限频 | 等待 30 秒后重试 |

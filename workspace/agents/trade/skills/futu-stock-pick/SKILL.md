# Futu Stock Pick - 港股/美股选股工具

基于富途 OpenAPI 的多因子选股模型，支持港股和美股市场。

## 功能特性

- ✅ 港股/美股主要指数成分股筛选
- ✅ 多因子模型（波动率、换手率、动量、Beta）
- ✅ 实时行情数据获取
- ✅ 支持模拟盘/实盘环境

## 支持的市场

| 市场 | 代码前缀 | 成分股指数 |
|------|----------|------------|
| **港股** | `HK.` | 恒生指数、恒生科技指数 |
| **美股** | `US.` | 标普 500、纳斯达克 100 |

## 筛选条件

| 因子 | 计算方式 | 排序 | 筛选比例 |
|------|----------|------|----------|
| 252 日波动率 | 过去 252 日收益率标准差 | 越低越好 | 前 50% |
| 5 日平均换手率 | 过去 5 日换手率均值 | 越高越好 | 前 50% |
| 5 日价格动量 | 过去 5 日累计收益率 | 越高越好 | 前 30% |
| 20 日 Beta 值 | 相对基准指数的 20 日 Beta | 越高越好 | 前 30% |

**最终排序**: 过去 10 日价格动量（越低越好），输出 Top 10

## 使用方式

### 港股选股

```bash
cd ~/.openclaw/workspace/agents/trade/skills/futu-stock-pick

# 港股选股（恒生指数成分股）
python3 futu_stock_pick.py --market HK --index HS

# 港股选股（恒生科技指数成分股）
python3 futu_stock_pick.py --market HK --index HSTECH
```

### 美股选股

```bash
# 美股选股（标普 500 成分股）
python3 futu_stock_pick.py --market US --index SPX

# 美股选股（纳斯达克 100 成分股）
python3 futu_stock_pick.py --market US --index NDX
```

### 参数说明

```bash
python3 futu_stock_pick.py \
  --market HK \              # 市场：HK/US
  --index HS \               # 指数代码
  --top-n 10 \               # 输出数量
  --date 2026-03-25          # 选股日期
```

## 配置

### 环境变量

```bash
# ~/.openclaw/.env
FUTU_HOST=127.0.0.1
FUTU_PORT=11111
FUTU_MARKET=HK
FUTU_ENV=SIMULATE
```

### 可调参数

```python
# 筛选比例
VOLATILITY_PERCENTILE = 0.50   # 波动率前 50%
TURNOVER_PERCENTILE = 0.50     # 换手率前 50%
MOMENTUM_5D_PERCENTILE = 0.30  # 5 日动量前 30%
BETA_PERCENTILE = 0.30         # Beta 前 30%

# 最终输出数量
TOP_N = 10
```

## 注意事项

1. **行情权限**: 需要富途行情权限（LV1 或 LV2）
2. **数据限制**: 富途 API 有调用频率限制
3. **交易时间**: 非交易时间获取的是收盘价
4. **成分股更新**: 指数成分股定期调整，建议每周更新

## 故障处理

| 问题 | 解决方案 |
|------|----------|
| 连接失败 | 检查 OpenD 是否运行，端口 11111 是否监听 |
| 行情权限不足 | 在富途牛牛 APP 购买行情卡 |
| 数据返回为空 | 检查指数代码是否正确 |
| API 限频 | 等待 30 秒后重试 |
